Exclusion period related with the latency - lag period

Description

Usage

f_exclusion(formula, data, lag)

Arguments

formula

lin(lin_var1,..,lin_varm)+strata(strat_var1,...strat_varp)

data

initial data set

lag

latency period

Value

a data set with the exclusion updated

Examples

f_exclusion(formula,data,lag)
