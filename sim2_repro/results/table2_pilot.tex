\begin{tablenotes}\footnotesize
\item Cox model $\lambda(t) = \lambda_0(t)\exp(\beta x(t))$ with true $\beta_{\mathrm{Cox}} =     1$; ERR model $\lambda(t) = \lambda_0(t)(1 + \beta x(t))$ with true $\beta_{\mathrm{ERR}} = 1.109$. Each fit is compared with the true $\beta$ of the model it fits; the paper's value is $\beta(1 + \mathrm{bias}/100)$. True $x$: the same risk model fitted to the true cumulative exposure, separating risk-model misspecification and small-sample bias from measurement error.
\item $n_1 = 2000$, $n_2 = 500$ (at most 8 pairs each), $T^* = 60$, cumulative incidence about 10\%. Surrogate $C$ has compound symmetry ($\rho = 0.5$) across years, $E(C) = 0.012$; true $c = \gamma_1 C + \epsilon$ with $\gamma_1 = 2/3$ (additive) or $\log c = \gamma_0 + \log C + \epsilon$ with $E(c) = 0.008$ (multiplicative), $\sigma_\epsilon$ set by $\rho(c, C)$; median $x$ 0.21 (additive) and 0.18 (multiplicative).
\item Pairs dropped: share of validation pairs with $c \le 0$ or $C \le 0$, which the log (.M) calibration cannot use. -- : no fit converged, or not recorded. A median of 50.00 means at least half of the fits stopped at the cap $\beta = 50$.
\end{tablenotes}
