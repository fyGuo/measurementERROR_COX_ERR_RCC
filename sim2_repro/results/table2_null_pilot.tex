\begin{tablenotes}\footnotesize
\item Cox model $\lambda(t) = \lambda_0(t)\exp(\beta x(t))$ and ERR model $\lambda(t) = \lambda_0(t)(1 + \beta x(t))$, both with true $\beta = 0$: the hazard does not depend on $x$, so Cox and ERR truth generate the same data and every fit should estimate 0. True $x$: the same risk model fitted to the true cumulative exposure.
\item $n_1 = 2000$, $n_2 = 500$ (at most 8 pairs each), $T^* = 60$, cumulative incidence about 10\%. Surrogate $C$ has compound symmetry ($\rho = 0.5$) across years, $E(C) = 0.012$; true $c = \gamma_1 C + \epsilon$ with $\gamma_1 = 2/3$ (additive) or $\log c = \gamma_0 + \log C + \epsilon$ with $E(c) = 0.008$ (multiplicative), $\sigma_\epsilon$ set by $\rho(c, C)$; median $x$ 0.21 (additive) and 0.17 (multiplicative).
\item Pairs dropped: share of validation pairs with $c \le 0$ or $C \le 0$, which the log (.M) calibration cannot use. -- : no fit converged, or not recorded. A median of 50.00 means at least half of the fits stopped at the cap $\beta = 50$.
